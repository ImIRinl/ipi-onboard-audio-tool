# IPI 板载音频上传工具

非官方、本地运行、无第三方运行依赖的 WebHID 工具。用于将本地音频转换并写入 IPI 鼠标音频槽位，不刷写或修改固件。

## 功能范围

- 选择本地音频，在浏览器内转换为 8 kHz / 8-bit / 单声道 PCM WAV。
- 手动上传指定槽位，覆盖前显式确认；上传后逐字节回读校验。
- 读取音效槽位、试听板载内容、导出 JSON 音频备份。
- 选择一个提示音启用，读取或调整板载音量。
- 音频处理在本机完成，不发送到服务器。静态服务只监听 `127.0.0.1`。

**不支持左右键独立音效。** 原厂 v1.2.2 虽能保存不同按键绑定，实际播放仍使用左键绑定。本版仅提供单一提示音选择，不承诺同时混音或独立关闭右键。选择绑定成功不代表已通过听觉验证。

仅音频上传、回读及备份流程在有线 v1.2.2 设备上得到实机验证。代码包含无线接收器的设备标识，但不承诺所有无线模式、硬件或固件版本均兼容。

## 使用方法

1. 安装 Node.js 18 或更高版本，使用桌面版 Chrome 或 Edge。
2. 下载并解压本仓库，Windows 双击 `启动工具.cmd`；或在项目目录运行 `npm run dev`。
3. 打开 `http://127.0.0.1:4173`，关闭官方驱动的设备页面以避免 HID 占用。
4. 点击“连接 IPI 鼠标”，选择对应设备。建议先用数据线连接。
5. 点击“备份全部音频”并保存 JSON，随后选择本地音频、名称和槽位，点击“写入板载存储”。
6. 回读验证完成后，在槽位卡片点击“启用此音效”。试听按钮通过电脑播放，不是远程触发鼠标音箱。

无需 `npm install`。直接双击 HTML 的 `file://` 方式不受支持。备份导出不是完整设备固件备份，本版不提供一键导入恢复功能。

设备标识：VID `372E`；有线 PID `10F8`，无线接收器 PID `10F9`；WebHID usage page `FF04`、usage `1`、report ID `8`。

## 风险与限制

这是非官方实验性设备工具，不能保证适配所有设备。上传会改写音频槽位，覆盖不可自动撤销，务必先备份；写入期间不要拔线、断电或同时操作其他驱动。即使不刷固件也存在设备通信、存储损坏或设置丢失风险。

本仓库不包含官方升级器、原厂或修改固件、签名密钥、设备音频、个人日志、USB 诊断、逆向得到的厂商网页脚本及任何救砖程序。不要将本工具当作固件修复方案。
